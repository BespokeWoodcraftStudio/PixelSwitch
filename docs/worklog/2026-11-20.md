### Decisions
- **NOT driving Claude Code's own reset** (round 2, 2026-11-20). Claude Code's reset is switched off by Anthropic for the one account that could be checked, and its confirm prompt defaults to Yes, so PixelSwitch will not drive it. Option B (show a Reset button only if Anthropic turns it on, open Terminal at its prompt) was not taken: today the button would never appear. Revisit only if Anthropic turns Claude Code's reset on.
- **NOT imitating claude.ai or Claude Code** (unchanged from 2026-11-19, and "you absolutly do not execute a reset"). A one-click reset inside PixelSwitch needs PixelSwitch to pretend to be one of them; we will not. No direct call to the reset or grant endpoints, no User-Agent change, no in-app claude.ai sign-in window. A repo-wide test pins it.
- **NOT removing the Limit resets button** (option C): option A gives two clicks per reset on the right account.
- The Chrome profile is matched by Google account email, and a missing profile is created (named "PixelSwitch <email>") on the first click, because he signs in to claude.ai once per profile.

### Lessons

Render and click through a flow (or prove the sign-in route works) before the founder picks it, never put a flow in front of him as a description.
- The server's "surface" gate (see WL-2026-11-19-001) still holds: only claude.ai and Claude Code get reset offers.
- This repository's `CLAUDE.md` is a symlink to `AGENTS.md`; edit and stage `AGENTS.md`.
